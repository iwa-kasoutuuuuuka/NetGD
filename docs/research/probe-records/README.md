# プローブの記録

`tools/gdprobe` の記録ファイルを置く場所。手順は [`../stock-gdemu-flow.md`](../stock-gdemu-flow.md)。

- ファイル名には、機器（`stock` / `netgd`）・日付・連番を入れる（例：`stock_20261121_01.txt`）。
- 1つの記録に複数のイメージの結果が入る。各行の `image=` がフォルダ番号。
- 記録を置いたら、何を調べた回か（SD の構成、イメージの種類、ファームの版）を `../LOG.md` に新しい項目として書く。
- イメージそのもの（`.gdi` / `.bin` / `.cdi`）はここに置かない（著作物のため）。ハッシュの照合は手元のファイルで行う。
