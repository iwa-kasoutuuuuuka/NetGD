## G1（6.0 対応）への影響

1. **MCU：SAM3U2E。** 既存の `sam3u2e` feature（`link/sam3u2e.x`、CDDA リングを NFC SRAM に移す、`MAX_IMAGES` を制限）で
   ビルドできる見込み。ただしフラッシュが 128 KB しかなく、ビットストリームを2つ目のプレーン（`.flash1`）に置く今の構成は
   使えない。AGM のビットストリームの大きさ次第で、**SD カードから読み込む方式**への切り替えが必要になる可能性が高い。
2. **FPGA：AGM AG16K。** Cyclone II 用の Quartus プロジェクトはそのまま使えない。AGM の開発ツール（Supra）を使う必要がある。
   Amaranth が出力する Verilog は流用できる見込みだが、PLL などの IP（`fpga/Quartus/ip/*`）は作り直しになる。
   パッシブシリアルでのコンフィグが Cyclone 互換かどうかは要調査。
3. **ピン配置：** FPGA が BGA なので、目視で配線を追うのは難しい。MCU 側のピン（SMC バス・HSMCI・FPGA コンフィグ線）が
   v5.5 と同じかどうかを導通チェックで確かめる必要がある。
4. **デバッグ用ヘッダ：** SWD がどのヘッダに出ているかをテスターで特定する（GND と SAM3U の SWDIO/SWCLK ピンとの導通）。
